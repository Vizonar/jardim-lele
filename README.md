# 🌷 Jardim da Lele

Site com flores e costelas-de-adão animadas, feito para abrir no celular.

- O jardim começa com uma tulipa branca no meio.
- Na barra de baixo, escolha a planta (tulipa, rosa, margarida, girassol, lírio,
  orquídea, lavanda, costela-de-adão ou costela-de-eva) e a cor (ou 🎲 para cor surpresa).
- Aperte no jardim para plantar. Com o regador, toque nas plantas para regar.
- O jardim fica salvo no aparelho. ↩️ desfaz, 🗑️ recomeça, 📷 tira foto,
  🎵 liga a música e 🌙 troca dia/noite (automático pelo horário).
- Ao mudar `style.css` ou `script.js`, aumente o `?v=` no `index.html` para
  o navegador não usar a versão antiga guardada.
